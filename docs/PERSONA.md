# Клиника PERSONA — адаптер выгрузки

Код: `src/embryo/clinics/persona.py`, `scripts/persona_stage.py`; конфиг:
`config/clinics/persona/{columns,settings}.yaml`; тесты: `tests/test_persona_ingest.py`.
Сопоставление колонок подтверждено владельцем 2026-10-19.

## Формат выгрузки

Одна книга на год (`data/inbox/PERSONA/`), данные — лист `нов<год>` (остальные листы —
шаблоны и справочники; в книге 2025 есть и копия `нов2024 (2)`, она не читается).
Заголовок в 2023/2024 — первая строка листа, в 2025 — вторая; ищется по маркеру
«Категория программы». Ниже данных ~90 тыс. пустых отформатированных строк.

Одна строка = одна **программа** (`Категория программы`: ТВП, КРИО ПЕ, Без ТВП, ТВП ДО,
Снято…, PRP, ТЕЗА). Лабораторная воронка — блоками по методу:

| Блок | Смысл | В лабораторной популяции |
|---|---|---|
| `кЭКО …` | обычное ЭКО | да, метод IVF |
| `И …` | ИКСИ / ПИКСИ | да, метод ICSI |
| `DO …` | реципиенты донорских ооцитов | да, метод не указан, `oocyte_source=donor` |
| `ЗО …` | заморозка ооцитов (только ОКК/MII) | нет — оплодотворения нет |
| `∑ …` | итог = кЭКО + И + DO | только сверка при staging |

Поля блока: Получено ооцитов → `occ`, Зрелых (MII) → `mii`, Норм.опл. → `two_pn`,
атрез. → `degrade` (DegR), Дробление → `cleavage_d3`, Выход б/ц → `bl_total`,
«Бласт н.луч качества минимум 3ВВ» → `bl_good` (≥3BB), ПЭ 3-4 / 5-6 сутки →
`transferred`, n заморож.эмбр → `frozen`. «Аномал.опл.» не сопоставляется (смешивает
1PN/3PN) — 3pNR недоступен. Сверка ∑ на всех трёх годах: совпадение 99.7–100%.

## Решения владельца (2026-10-19)

- **Смешанный цикл ЭКО/ИКСИ** — две строки широкой lab-популяции (`lab_part` ivf/icsi),
  `_key` получает суффикс блока (`run_analysis._add_opu_aliases`). Σ/Σ-показатели от
  раскладки не меняются; в отчётной когорте (DT) цикл остаётся одной строкой.
- **Дата пункции** = «Дата Программы» у программ с лабораторным блоком (проверено:
  Дата переноса − Дата Программы = День ПЕ у ~98% свежих ТВП 2024/2025). У КРИО ПЕ
  та же колонка — дата переноса. **Год отчёта** — год «Дата Программы».
- **Межфайловые дубли**: файл 2023 содержит 35 программ января–февраля 2024, они же есть
  в файле 2024. Остаётся строка из книги того же года.
- **Исход** (клиническая беременность по УЗИ, включая внематочную): `результат УЗИ 2`
  = пол или отметка внематочной → 1; ХГЧ «отр» или УЗИ «отр» → 0; иначе пропуск.
- **AFC в выгрузке нет**, фолликулов тоже («ТФС в день триггера» — не фолликулы: дробные
  значения, заполнена у криопереносов; вероятно толщина эндометрия). Для DT принято
  `afc_from_occ = round(собственные ОКК × 1.16)`, у цикла только на донорских ооцитах —
  `round(ОКК донора × 1.16)` с флагом `afc_from_donor_occ` (AFC донора при возрасте
  реципиентки — двойная условность, называть в интерпретации) — коэффициент ΣКАФ/ΣОКК на Fertimed
  (обоснование и разбивка — комментарий в `settings.yaml`). Колонка идёт только во вход
  DT (`impute.afc_columns`, флаг `afc_source=afc_from_occ`), не в лабораторные KPI и не в
  импутацию АМГ. OCCR недоступен.
- **Freeze-all не исключается** из таблиц компетентности эмбриологов/врачей (в отличие от
  Fertimed): таблицы строятся на всей лабораторной работе — FR/BlR/TGBDR не зависят от
  того, был ли свежий перенос, а freeze-all у PERSONA ~800 строк-блоков в год (~45%).
  Флаг `freeze_all` (`ОП/ЕТ` = ОП и заморожен ≥ 1 эмбрион программы) остаётся в staged
  как контекст и для связки с криопереносами; при необходимости исключение включается
  строкой `competency_exclusion.freeze_all_flag_column: "freeze_all"`. Флаг определяется
  не по причине отмены: причины разнородны, в 2025 у 155 отмен пусты.
- **Донорские ооциты** (блок DO) — в KPI с флагом донора. DT прогнозирует такие циклы по
  возрасту реципиентки — ожидание занижено; в интерпретации называть.

## Правдоподобие и приватность

- ИМТ вне `persona.bmi_plausible` [12, 70] → пропуск (в выгрузке есть 0, 163, 442);
  попытка ≤ 0 → пропуск; АМГ — текст с десятичной запятой, нечисловое → пропуск.
- `patient_id` = ФИО|дата рождения (локальный ключ, одинаковый между годами; ИИН есть
  только в 2025 и не используется). Staged-файлы — только `local_private/staged/`.
- Демо-экспорт (`demo_export/persona_<год>.csv`) — без ФИО и даты рождения;
  идентификатор — HMAC (пациентка + дата пункции + блок), секрет клиники.

## Запуск

Команда Claude Code: `/run-persona <год>` (`.claude/commands/run-persona.md`).

```
python scripts/persona_stage.py                         # staged + демо-экспорт + циклы для Laya
python scripts/preflight.py --persona 2024
python scripts/run_analysis.py --persona 2024 --dt-check   # сухая проверка DT
python scripts/run_analysis.py --persona 2024              # полный прогон -> data/processed/persona/2024/
```

`--persona <год>` = `--clinic persona` + вход `staged/persona_<год>.xlsx` + выходы
(processed, local_private, agent_packets, crosswalk, выходы TabPFN/DNN/регрессии) в
`data/processed/persona/<год>/`. Секрет `cycle_uid` общий для всех лет и демо-экспорта.
Laya в пайплайне — без калибровки центра (`centre: ""`, статус `ok_uncalibrated`,
покрытие по `laya_raw`); restore Laya ставит фолликулы = ОКК, в отличие от демо-анализа
(`--impute-dt71`, `rint(ОКК/0.846)`).

Демо-дашборд: `ivf-lab-kpi-ews-demo`, `--input <demo_export/persona_<год>.csv> --name persona_<год>`.
Laya (уровень цикла, решение владельца): `scripts/ews_laya.py --name persona_<год>_cycles
--input <demo_export/persona_<год>_cycles.csv> --impute-dt71 --centre none` — фолликулы по
правилу DT 7.1 `rint(ОКК/0.846)` (согласие владельца 2026-10-19); калибровки центра PERSONA нет.
