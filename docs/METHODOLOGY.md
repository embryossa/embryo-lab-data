# Методология и источники

Основной внешний стандарт: Vienna consensus, PMID 28784335:

https://pmc.ncbi.nlm.nih.gov/articles/PMC6276649/

В коде `indicator_class` различает формальные Vienna KPI/PI, reference indicators и
локально принятый порог. Это важно для FR: для данной лаборатории владелец закрепил
единый benchmark 75%, тогда как первоисточник приводит для ICSI competence 65% и
benchmark 80%. Локальное решение не выдаётся за исходный Vienna benchmark.

Когортные доли вычисляются как `Σ numerator / Σ denominator`. Доверительный интервал —
двусторонний Wilson 95%. Для DegR и 3pNR контроль верхний; для остальных показателей —
нижний. OCCR вычисляется как OCC/follicles по принятому владельцем контракту; MIIR как
MII/OCC только при фактически известном MII.

Исходный `Data_Twin_analytics.ipynb` хранится неизменённым в `notebooks/reference/`.
Перенесённые формулы и исправления реализованы в тестируемых Python-модулях, поэтому
облачный DataLore не требуется для рабочего запуска.
